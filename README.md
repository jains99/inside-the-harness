# Inside the Harness

An interactive, single-page intro to how AI coding agents actually work — the model,
tokens, context windows, the agent loop, tool calls, streaming, caching, sessions, and
the harness around it.

**Live:** <https://jains99.github.io/inside-the-harness/>

## Run locally

Open `index.html` in a browser. No install, server, or API key is required. The
interactive demos need JavaScript; the text is readable with JavaScript disabled.

## Notes

- The "API calls" are simulated locally; no data is sent anywhere.
- Prices and model facts are examples. The page notes where behavior is model- or
  provider-specific.
- Best on a desktop screen; the mobile layout is not a supported target yet.
